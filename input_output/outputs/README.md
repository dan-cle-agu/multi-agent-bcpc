# Output artifacts

This folder contains all generated runtime artifacts for the project.

## Included outputs
- `test_results.csv`
- `workflow_diagram.md`

`test_results.csv` is regenerated by `python project_starter.py` after the evaluator passes its request-count, fulfillment, cash-change, managed-agent, and ledger-reconciliation gates. Temporary runtime logs and the SQLite database are excluded from version control.
