# Output artifacts

This folder contains all generated runtime artifacts for the project.

## Included outputs
- `test_results.csv`
- `workflow_diagram.md`

`test_results.csv` is mirrored here by `python project_starter.py`; the course-required canonical file is written at the project root. The evaluator checks request count, fulfillment/rejection outcomes, cash changes, and quote/sale reconciliation. Temporary logs and the SQLite database are excluded from version control.
